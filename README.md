# Air-Canvas-Project
Virtual Air Canvas using OpenCV and MediaPipe

## Hand Gestures & Controls

### Drawing
- Raise only the index finger to draw on the canvas.

### Stop Drawing / Finalize Shape
- Close the full palm (make a fist) to stop drawing or finalize shapes.

### Tool Selection
- Raise both index and middle fingers to enter selection mode.
- Touch buttons using fingertip to:
  - Select colors
  - Choose shapes
  - Change brush type
  - Enable eraser
  - Clear canvas

### Fill Tool
- Enable fill mode and touch inside any shape to fill color.

### Save Drawing
- Press `S` key to save the drawing.

### Exit
- Press `ESC` key to close the application.
